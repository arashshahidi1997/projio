# Hypothesis registry

The study's hypotheses, one entry each: the wording, the status in words **with the evidence it rests on**, and the
finding IDs that bear on it. The thread state docs (`<thread>/index.md`) hold the findings and their evidence; this
page only points at them.

**Rules.**

- A status always says what it rests on (subjects, sessions, datasets). An unqualified "supported" or "not
  supported" needs replication across the cohort; until then it reads e.g. "supported (1 subject, 2 sessions)".
- Status comes from finding IDs only. A result note without a finding ID is listed as "note only".
- New work is an O item in a state doc. This page never holds a to-do of its own.
- A retired ID is listed under Retired with what replaced it; IDs are never reused.
