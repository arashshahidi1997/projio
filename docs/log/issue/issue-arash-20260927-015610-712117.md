`note_create` MCP `frontmatter` param requires JSON and errors opaquely on YAML.

`mcp__projio__note_create(..., frontmatter=<YAML>)` — e.g. passing the on-disk frontmatter format:

    tags: [result, spindle]
    series: lfp_extrema

returns `{"error":"Expecting value: line 1 column 1 (char 0)"}` (a raw `json.loads` failure) with no
hint that a JSON object string is expected. Passing the same fields as a JSON string works:

    {"tags": ["result","spindle"], "series": "lfp_extrema"}

Footgun: notes store YAML frontmatter, so YAML is the natural thing to pass, and the error message
doesn't name the expected format. Fix options: accept YAML (yaml.safe_load fallback), and/or validate
with a clear message like "frontmatter must be a JSON object string, e.g. {\"tags\":[...]}". Hit in
pixecog 2026-09-26 (worked around by passing JSON).
