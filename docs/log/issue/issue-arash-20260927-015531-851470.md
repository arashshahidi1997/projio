`projio sync` crashes in `_sync_render_config` (AttributeError: 'list' has no 'relative_to').

Running `projio sync` in pixecog (2026-09-26) aborts with:

    File ".../projio/src/projio/sync.py", line 274, in _sync_render_config
        return {"action": "generated", "output": str(out_path.relative_to(root))}
    AttributeError: 'list' object has no attribute 'relative_to'
  (called from sync.py:1028 sync_workspace -> _sync_render_config)

`out_path` is a list, not a Path, so the `.relative_to(root)` report call throws. This aborts
`sync_workspace` AFTER library registration + include.lua succeed, so render-config sync and every
subsequent sync step never run — i.e. `projio sync` is currently unusable on this repo.

Repro: `/home/arash/.local/bin/projio sync` in /storage2/arash/projects/pixecog.
Likely fix: `_sync_render_config` now produces multiple output paths (a list); update the return to
iterate them (or `out_path[0]`) when building the relative-path report. Impact: blocks the
`/px-build-and-push` pre-build sync step (worked around by calling the individual
notio/pipeio/questio MCP doc-collect tools directly).
