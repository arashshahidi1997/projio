projio sync's managed .gitignore block ignores every directory named `site/` (a bare `site/` line between `# >>> projio` and `# <<< projio`), not just the mkdocs output. In pixecog this silently ignored a new `.projio/site/` folder (git check-ignore: `.gitignore:101:site/`), so the site plumbing had to go to `.projio/mkdocs/` instead (2026-11-08). Expected: anchor the pattern (`/site/`, or the configured `site_dir` such as `/_site/`) so nested dirs named `site` stay trackable.
