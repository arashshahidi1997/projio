pipeio docs_collect / docs_nav ignore the per-notebook `publish_html` flag.

Repro (pixecog, 2026-10-22): code/pipelines/preprocess_ieeg/notebooks/notebook.yml sets `publish_html: true` for only 2 notebooks (investigate_ttl_masking_characterization, investigate_ttl_xcorr_sync). But `pipeio_docs_collect` copied all 24 built HTMLs from code/pipelines/*/.build/notebooks/ into docs/pipelines/<flow>/notebooks/, and `pipeio_docs_nav` lists all of them under "Notebooks" in docs/pipelines/mkdocs.yml. preprocess_ecephys ttl_characterization (publish_html: false) and calibrate_ieeg_notch gfet_vs_npix_fig are also collected.

Impact: pixecog deploys GitLab Pages from a locally built _site/, so every built notebook ends up public on the site regardless of the flag. pixecog now gitignores unpublished HTML (commit 18c7e0d), but that cannot stop the local build from including them.

Expected:
- docs_collect copies `.build/notebooks/<name>.html` only when that entry has `publish_html: true`, and removes stale copies of unpublished ones from docs/pipelines/<flow>/notebooks/;
- docs_nav lists only the published ones;
- likewise `publish_myst` for the .md/myst outputs.
