[from pixecog] pipeio_nb_publish (and pipeio_nb_snapshot) fail for marimo notebooks. Re-check 2026-11-02: still unfixed. In packages/pipeio mcp.py, mcp_nb_publish still requires an .ipynb (nbconvert path) and has no branch for `format: marimo` in notebook.yml. The error is "ipynb file not found … Run pipeio_nb_sync first". pipeio_nb_sync doesn't apply to marimo .py notebooks. Requested: (1) detect format: marimo and run `marimo export html <nb.py> -o <out.html>` instead of nbconvert; (2) have docs_collect add the marimo HTML to the notebook index; (3) make nb_snapshot stop executing marimo notebooks as jupytext. Current pixecog workaround: run `pixi run python -m marimo export html` by hand. This matters more now because marimo-pair is pixecog's main exploratory mode. Origin: pixecog docs/log/issue/issue-arash-20260416-184632-937874.md (closed in pixecog with a pointer to this issue). The 2026-10-27 projio fix (publish_html flags) did not cover this.
