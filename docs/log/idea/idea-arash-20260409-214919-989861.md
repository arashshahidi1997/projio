## Add crossref DOI resolution to biblio MCP

Currently biblio resolves metadata via OpenAlex. Adding a crossref curl fallback would be useful for:
- Papers not yet indexed in OpenAlex (new preprints, niche journals)
- DOI validation / metadata cross-checking
- Getting structured reference lists when GROBID fails or PDF is unavailable

Could be a `biblio_crossref_resolve(dois)` tool or integrated into the existing `biblio_ingest` cascade as a fallback resolver.
