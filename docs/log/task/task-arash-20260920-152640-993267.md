## Slide structure (6)

1. **the mess** — PhD "Desk Entropy" comic + one line; origin story in notes.
2. **Data specification (BIDS)** — meal-prep photos (source → raw → derivative)
   with a robot chopping / cooking between them (a "SPECS" doc flies into each
   robot's head), curved arrows; staged reveal; ends on a question bubble
   *"how can we get derivatives and results reliably?"*
3. **Pipelines (Snakemake)** — 3 columns: "Let me do that by hand…" comic
   (animates setup → frustration strip), `workflow-dag.svg`,
   `snakemake-workflow-rules.png`; DataLad `local_wf` versioning figure
   bottom-left; reconstruction/trust story in notes.
4. **Exploration, grounded** — `explore-ground.svg`: surface (a Marimo notebook
   *or* a Python script) on top; your **code** + your **literature** ground the
   agent from below via **skills · MCP** (MCP command pills, a "skill" badge,
   Docling logo). Message: grounding cuts hallucination / reinvention.
5. **Publication (Quarto)** — BIDS-style staged flow (`results-folder.svg` →
   `robot-assemble.svg` (agent fed a SPECS doc, *assembling* one source) →
   `docs-stack.svg` (slides · manuscript · report, all showing the same live
   `4.2`)), curved arrows between; the results folder is the prior slide's
   deliverables; the identical `4.2` across all three docs carries the
   live-sync mechanism, so the token-plumbing schematic (`publish.svg`) is
   retired from the slide. Blue capabilities bubble ("agent knows the tools; I
   describe what I want").
6. **Conclusions** — full-stack animated **spotlight recap** (each component
   lights up in turn; the plant grows through notebooks→pipelines→publication)
   medium-left; right panel: **sustainable science** (reproducible · adaptable ·
   transparent, vertical) + **workshop QR**. Subtitle: *"the conventions are the
   rules of the game; the agent knows how to play."*
